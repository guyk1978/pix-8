## What Is a Photo Overlay?

A photo overlay is a **transparent PNG or SVG graphic** placed on top of your original image. Unlike a full filter that changes every pixel, an overlay sits in a specific visual layer — you control where it appears, how large it is, how transparent it is, and how it is rotated.

Common overlay categories include:

* **Stars and sparkles** — birthdays, announcements, night-sky portraits, festive Stories
* **Flowers** — weddings, spring campaigns, beauty and lifestyle content
* **Birds** — travel, nature, poetic or minimalist aesthetics
* **Hearts** — Valentine's posts, thank-you graphics, community shout-outs

The Pix-8 editor ships with a curated preset gallery covering these styles, so you can start creating immediately without hunting for assets online.
