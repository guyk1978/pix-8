# מדיניות פרטיות

Pix-8 בנוי סביב **עיבוד תמונה מקומי (local-first)**. התמונות והעריכות שלכם נשארות במכשיר אלא אם אתם בוחרים להוריד או לשתף אותן בעצמכם. מדיניות זו מסבירה מה אנחנו אוספים, מה לא אוספים, ואיך עובדות תכונות האתר האופציונליות.

## מה אנחנו לא עושים

* **אנחנו לא מעלים את התמונות שלכם.** כל כלי Pix-8 רץ בדפדפן. קבצים שבוחרים נקראים מקומית ומעובדים במכשיר.
* **אין חובה לפתוח חשבון** כדי להשתמש בכלים הבסיסיים.
* **אנחנו לא מוכרים מידע אישי.**

## מידע שנשמר במכשיר שלכם

Pix-8 עשוי לשמור כמויות קטנות של נתונים בדפדפן כדי שהאתר יעבוד כמצופה:

| נתון | מטרה |
| :--- | :--- |
| **העדפת שפה** | לזכור את שפת הממשק שבחרתם |
| **העדפת ערכת נושא** | לזכור מצב בהיר או כהה |
| **בחירת הסכמה לעוגיות** | לזכור אם אישרתם או דחיתם עוגיות אנליטיקה |
| **מועדפים** | לזכור כלים שסימנתם בכוכב (מקומי בלבד) |
| **דירוגי כלים** | לזכור דירוגים ששלחתם לכל כלי (מקומי בלבד) |
| **פרויקטים** | לשמור עבודה בתהליך בדפדפן כשמשתמשים בתכונות פרויקט |
| **מטמון מודלים** | לאחסן מודלים מקומיים (למשל הסרת רקע) ב-IndexedDB ולהימנע מהורדה חוזרת |

אפשר למחוק נתונים אלה בכל עת דרך הגדרות הדפדפן.

## עוגיות אנליטיקה (אופציונלי)

אם **מאשרים** את באנר העוגיות, אנו עשויים לטעון **Google Analytics** כדי להבין איך הכלים בשימוש ולשפר את המוצר. האנליטיקה **לא** מקבלת את קבצי התמונה שלכם.

אם **דוחים**, סקריפטי האנליטיקה לא נטענים. תכונות מסוימות שתלויות בהסכמה עשויות להישאר מוגבלות עד לאישור.

אפשר לשנות את הבחירה על ידי ניקוי נתוני האתר וביקור חוזר ב-Pix-8.
